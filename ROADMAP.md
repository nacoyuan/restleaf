# Roadmap / 后续计划

RestLeaf is deliberately small. These are directions, not delivery commitments.

- [x] English and Simplified Chinese UI; system language and manual override.
- [x] Away / Resume Timer and Start Over.
- [x] Timer-state tests and localization checks.
- [ ] Developer ID signing and notarized distribution.
- [ ] Independent tests across supported macOS versions and multiple displays.
- [ ] Reproducible full-app build checks on additional Xcode/SDK versions.
- [ ] Improve VoiceOver and keyboard-only workflows based on real feedback.

保持功能克制。接下来优先完善正式签名与公证、更多系统与多屏实测、构建兼容性和无障碍体验；以上不是上线时间承诺。
