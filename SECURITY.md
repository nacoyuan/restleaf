# Security / 安全

RestLeaf is a local-only app with no account or network service. Security fixes focus on the latest released version; there is no guaranteed response-time SLA.

Please use the repository's **Security → Report a vulnerability** private reporting feature for sensitive reports. Do not put secrets, private files, or exploit details in a public issue. Ordinary timer bugs and feature requests belong in Issues.

歇一会没有账号和联网服务，安全修复以最新发布版本为主，不承诺固定响应时限。敏感安全问题请使用仓库 Security 页面的私密漏洞报告入口，不要在公开 Issue 中放置密钥、私人文件或利用细节；普通计时问题请使用 Issues。
